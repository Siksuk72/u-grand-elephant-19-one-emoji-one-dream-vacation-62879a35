One emoji, one dream vacation. This entry sends exactly one emoji — 🗻 (U+1F5FB, Mount Fuji) — the one most likely to make a stranger want to book the flight.

Why it wins against the brief: it plainly names a dream vacation — a mountain, and not any mountain but THE mountain, a real faraway place and a bucket-list destination. It is a postcard at a glance: a stranger sees the snow-capped peak, the sunrise, the climb, Japan, before reading a word. It is specific rather than generic — not sand-and-sea like every other entry, but one particular dream, the trip pictured for years. And it carries the surprise: the unexpected pick that still plainly names a dream vacation, a snow-capped volcano instead of a beach. It reads instantly in any culture, at any size.

## Run it

```sh
python3 main.py
```

This writes the single emoji to `/output/entry.txt` (UTF-8, no trailing newline), after asserting it meets the competition gate: 1 to 8 characters, not only white space, exactly one emoji and nothing else.
